# browser-bookmark-homepage

When the user wants a personal start/nav homepage built from Chromium or Comet bookmarks, or an auto Top-N frequent-sites section from browser History visit counts. Not for Firefox-only workflows, writing browser extensions, or deploying self-hosted OneNav.

## 安装

```bash
npx -y skills add miguelhsiung-collab/browser-bookmark-homepage -g --all
```

## 使用

安装后，可以这样开始：

> 使用 $browser-bookmark-homepage 完成它所解决的任务，并按可观察标准检查结果。

## 运行依赖

- 支持 Agent Skills 的客户端
- Python 3（用于运行 Skill 内脚本）
